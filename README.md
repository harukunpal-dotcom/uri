# URI System Monitor

Ubuntu / Linux 向けのデスクトップ型システム監視アプリです。CPU・メモリ・ディスク・ネットワークの状態を1秒ごとに更新して表示します。

## 機能

- CPU 使用率（リアルタイム）
- メモリ使用率と使用量
- ホームディスク使用率と空き容量
- CPU温度（Linuxのセンサー情報が公開されている場合）
- ネットワーク受信・送信速度
- CPU・メモリ・ネットワーク速度の直近60回のグラフ
- パソコンの稼働時間

## 必要なもの

- Ubuntu / Linux
- Python 3
- Tkinter

## インストール

Ubuntuのターミナルで実行します。

```bash
sudo apt update
sudo apt install python3-tk
```

## 起動

リポジトリをダウンロードし、フォルダ内で実行します。

```bash
python3 main.py
```

## CPU温度について

CPU温度は `/sys/class/thermal/` と `/sys/class/hwmon/` のセンサー情報を読み取ります。PCやドライバーによっては温度情報が公開されていないため、その場合は「センサー情報を取得できません」と表示します。温度が表示されなくても、他の機能は使用できます。

## 仕組みとプライバシー

追加のPythonライブラリやインターネット接続は不要です。Linuxの `/proc` と `/sys`、Python標準ライブラリを使って情報を読み取ります。設定変更、ファイル削除、外部へのデータ送信は行いません。
